Reproduce the hardware demonstration

Run from the repository root. The delivered files are editable. No proprietary tools are required for these demonstrations.

SPICE

python -X utf8 hardware/run-spice.py

Requires ngspice on PATH (verified ngspice 47). static-branches.cir reproduces published static branch expressions, encoding displacement as a behavioral output. It is not a dynamic capacitor with validated terminal energy. teaching-cell.cir uses an assumed normalized double-well state, programming pulses, and a simplified read-current expression. It does not reproduce a measured full FeFET.

The runner checks static Python agreement, positive/negative state/read distinction, halved timestep, and an independently executed SciPy ODE solution. Inspect spice-validation.json, simulator logs, .dat tables, and cell-waveform.svg. Tightened tolerances repair the original default-tolerance static discrepancy. No author Verilog-A source was available, so portability of such a source is not claimed.

Digital logic

bash hardware/run-rtl.sh
python -X utf8 hardware/plot-rtl.py

Icarus Verilog 12 and Yosys 0.33 were installed in the existing Ubuntu WSL environment for this task. controller.v is synthesizable. memory-behavior.v is a simulation-only 16×8 memory, separate from controller synthesis. tb.v verifies 11 transactions plus protocol/reset boundaries, using default read/write latencies of two/four cycles. Faulted writes do not commit, faulted reads return zero with error, busy requests do not replace accepted commands, and reset aborts a pending command without clearing the external memory.

run-rtl.sh executes RTL, synthesizes the controller into generic logic, then runs the same testbench on the synthesized netlist. Both logs must contain PASS and no fatal failure. controller.vcd is the actual simulated trace; plot-rtl.py extracts it into annotated controller-waveform.svg. The waveforms do not come from a hand-drawn expected trace.

The analog and digital simulations are not co-simulated. Cycle counts are not calibrated from measured device latency. The behavioral memory does not synthesize into a research ferroelectric macro. Generic logic has no foundry clock frequency, timing closure, silicon area, or power characterization.

Physical illustrations and abstract views

python -X utf8 hardware/draw-design.py
python -X utf8 projects/stack.py placement

Outputs: cross-section.svg, cell-schematic.svg, array-organization.svg, floorplan.svg, memory-abstract.lef, abstract-tech.lef, memory-abstract.gds, and abstract-macro.json. The LEF supplies 25 pins and an assumed 80×100 µm macro boundary. The GDS supplies one outline and 128 symbolic cell rectangles on arbitrary layers. Checks verify geometry, file-record structure, pin containment, and SVG XML; they are not external GDS-reader signoff or foundry DRC.

The separate placement study uses a 10 mm point-macro teaching problem. Its units and scale are intentionally independent of the illustrative 600×400 µm floorplan. Neither is a routed design. No Liberty timing tables are invented.

Unsupported physical steps require: a compatible process kit, standard-cell timing/layout views, qualified research-device models, cell design rules, extraction decks, a characterized memory macro, and a supported place/route/signoff flow. Without those dependencies, clock-tree synthesis, routing, STA, DRC, LVS, PEX, and post-layout simulation cannot honestly be completed for this stack. Fabrication is outside this demonstrator.

See research/feasibility.html and research/parameter-ledger.csv for source and calibration boundaries. The repository contains the editable simulation examples and saved results; original publications remain linked at their sources.
