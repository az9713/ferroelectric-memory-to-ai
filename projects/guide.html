Run, change, and defend the projects

All baseline projects run on the tested development environment. Python 3.13, NumPy, SciPy, and Matplotlib were used for calculations; exact installed versions are recorded in the verification report. No proprietary solver is needed for the delivered projects. Research papers using Sentaurus are discussed as sources, not reproduced through an unavailable license.

Open a terminal in the repository root. Use a Bash shell for the RTL command (Linux, macOS, or WSL on Windows). Each command below writes local results. Reruns replace generated result files; preserve a copy before exploratory changes. The HTML lessons link to original papers at their publishers and repositories. Parameters and random seeds are declared in editable scripts. The baseline synthetic noise uses seed 1989.

cd ferroelectric-memory-to-ai
python -X utf8 projects/polarization.py
python -X utf8 projects/stack.py all
python -X utf8 projects/capstone.py
python -X utf8 hardware/run-spice.py
bash hardware/run-rtl.sh
python -X utf8 hardware/plot-rtl.py
python -X utf8 hardware/draw-design.py

Python is an interpreter: the script executes statements and calls numerical libraries. Arrays in NumPy hold sampled values; SciPy supplies solvers; Matplotlib writes figures. Read function definitions and their units before changing constants. An assertion stops execution when a specified check fails. Passing assertions confirms those checks, not every possible use of the model.

Project contracts

Project / questionVariables, objective, constraints, and rangesBaseline, solution, and learner extension
Foundations: how does an interface alter electrostatics?Temperature fixed 300 K; interface thickness 0.25, 0.5, 1, 2 nm. Compute voltage partition and opposing field at fixed assumed polarization. A sensitivity sweep, not an optimization.stack.py foundations; result. Check zero terminal voltage. At 1 nm, fixed-P opposing field is about −2.039 MV/cm: solve self-consistently before treating it as stable. Extend by imposing a stability constraint.
Static fitting: which parameters are identifiable?Fit saturation, remanence ratio, coercive field, background permittivity, and offset to synthetic noisy displacement. Least-squares objective with explicit physical bounds; hold out every third point. Saturation-only fits test ambiguity.polarization.py; result, curve data. Held-out RMSE about 0.102 µC/cm². Change sampled field range and noise; compare multiple fits. This is a local nonlinear fit, not a proof of global uniqueness.
Switching: what field meets a pulse-failure target?Assumed Merz law, 100 ns pulse, field 0.5–3 MV/cm in 0.025 steps; minimize field subject to failure probability ≤10⁻⁶. Separate normalized ODE uses 20 ns relaxation.stack.py switching; result. Lowest feasible grid field 1.025 MV/cm. Refine grid, vary activation field and pulse width. Do not confuse this hazard model with the separate ODE or measured lifetime.
Reliability: can ECC and wear spreading help?72-bit word, independent raw error 10⁻⁵; exact binomial probability of ≥2 errors. Assumed 10⁶ cycles, 1,024 locations, 100 logical writes/s, amplification 2. No free optimizer.stack.py reliability; result. Uncorrectable probability ≈2.555×10⁻⁷; ideal wear lifetime 5.12×10⁶ s versus 5,000 s hotspot. Add correlated failures or imperfect wear distribution.
Array optimization: which organization is feasible?24 choices: banks 1–32 powers of two, width 32/64/128/256 bits; fixed 64 MiB. Constraints: ≤15 ns, ≤30 mm², BER ≤10⁻³. Pareto objectives: access pJ, ns, mm². Final selection minimizes pJ/byte.stack.py arrays; all choices, solution. Selected 32 banks ×256 bits, 5.208 pJ/byte. Distinguish the access-energy Pareto set from the per-byte selection objective. Modify peripheral and wire coefficients; retain infeasible points.
Placement: where should a macro sit?Point-macro grid 1–9.75 mm in 0.25 steps; keepout [4,6]². Minimize weighted Manhattan distance to three interfaces. Fixed chip outline, weights 1/1/2.stack.py placement; result. Best weighted distance 26 mm, one minimizer (1,5); ties possible. This 10 mm teaching geometry is separate from the 600 µm illustrative floorplan. Add finite macro dimensions before claiming packing feasibility.
Workload optimization: which batches fit?Batches 1/2/4/8/16; contexts 128/512/1024/2048. Maximize tokens/s subject to capacity ≤64 MiB and step ≤5 ms. Compute 1 TFLOP/s, interface cap 80 GB/s, fixed assumed quality.stack.py workload after arrays; choices. Broad-sweep best B16/S128. For a fair comparison, fix context and optimize batch only. Inputs are a toy model, not an actual LLM configuration.
Precision: how many bits satisfy error?Seeded 64×64 random weights and 64×32 inputs; quantize at 2/3/4/6/8/12/16 bits. Minimize weight bytes subject to relative output norm error ≤2%.stack.py precision; result. Eight bits selected, error ≈0.837%; six bits fail. Test outliers and nonuniform inputs. Random linear-layer error is not language-model accuracy. Prefill compute lower bound is separately calculated.
System optimization: which utilization minimizes energy within latency?Utilization 0.1/0.3/0.5/0.7/0.9/0.98. Minimize facility J/token subject to modeled mean batch response ≤5 ms and IT power ≤100 W. Idle 45 W, PUE 1.2.stack.py system after workload; result. Selected 0.7, 3.184 mJ/token. Compare analytic bound 0.8721 and refine grid; sensitivity uses idle 25/45/80 W and PUE 1.1/1.2/1.5. No tail-latency certification.
Capstone: what survives the whole chain?Polarization 0.08/0.10/0.13/0.16 C/m²; standard-deviation factors 0.8/1/1.2; fixed/reselected array. Fixed B16/S128 and quality; assumed read coupling and energy scaling.capstone.py; 24 scenarios. Nominal read-window requirement 0.3288 V; inferred polarization ≥0.10686 C/m² only under assumed coupling. Baseline matches preceding stages; failed reliability remains visible.

Common interpretation errors to catch

Do not combine the synthetic 10 nm capacitor with the thesis's 5 nm p-channel device and call the result calibrated. Do not convert loop loss directly into complete memory access energy. Do not multiply an Amdahl speedup by an unrelated energy factor. Do not shorten context or reduce quality and call it the same task. Do not label a finite grid optimum globally optimal over all possible designs.

The cumulative numerical interface is explicit: array output supplies capacity, bandwidth, and pJ/byte to the workload; workload output supplies step time and dynamic J/token to the system; capstone holds that scenario fixed while varying declared couplings. Static polarization and transient dynamics remain separate demonstrations because a verified physical connection is missing. The separation is a scientific limitation, not an invitation to invent the connection.

Reproduction and repair

Run the baseline before editing. If an assertion fails, record the changed input and whether the failure is numerical, physically infeasible, or a mistaken expectation. Compare analytical limits and units first. Solver agreement checks implementation; validation against a new measured condition checks predictive scope. The complete engineering instructions explain SPICE tolerances, RTL tests, and abstract geometry checks.
