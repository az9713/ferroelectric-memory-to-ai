Chapter 8 · Chip and package · 10–14 hours

Physical integration and its evidence boundaries

What does “CMOS-compatible” actually establish?

A circuit diagram does not specify how to manufacture a chip

A schematic tells us which electrical elements connect. Manufacturing also requires their physical dimensions, materials, spacing, and processing sequence. A device cross-section describes vertical layers; a layout describes shapes placed on fabrication layers. A package connects the completed chip to the outside world and provides mechanical and thermal paths. These are different descriptions of the same intended system.

A memory macro is a block presented to a chip designer with specified connections and behavior. To use it, the designer needs consistent information about its footprint, pins, electrical loads, timing, power, and permitted operating conditions. A rectangle marked “memory” provides only a small part of that information.

A process design kit, or PDK, supplies rules and models for a particular fabrication process. Placement chooses where cells or blocks go; routing chooses physical wire paths. Design-rule checking tests specified geometric restrictions, while layout-versus-schematic checking compares extracted connectivity with the intended circuit. Passing one kind of check cannot stand in for all the others. These definitions make the limitations of the course's deliberately abstract physical views precise.

Prerequisites: Chapters 5–7. Objectives: follow cross-section to chip hierarchy; distinguish synthesis, placement, routing, and verification; reason about thermal budget and yield; and inspect an abstract macro without mistaking it for a finished bitcell.

8.1 The hierarchy carries different kinds of information

A device cross-section describes layers and geometry. A cell schematic specifies electrical connectivity. An array organization specifies selection and sharing. A macro abstract supplies the block's footprint, pins, obstructions, and interface assumptions to higher-level design. A chip floorplan locates blocks and reserves routing and power resources. None of these views can replace the others.

Our memory abstract stores 128 logical bits in sixteen 8-bit words. Its chosen footprint is 80 by 100 µm, with a 4 µm symbolic cell pitch and generous periphery. Those dimensions make the hierarchy readable. They are independent of the hypothetical dense-array assumptions in the numerical system study; scaling the demonstrator footprint to claim that study's density would mix unrelated models.

8.2 A PDK is a process contract

A process design kit, or PDK, provides the layer vocabulary, device definitions, design rules, electrical models, and verification support for a manufacturing process. Standard-cell libraries add characterized gates and registers, their layouts, timing, power, and permitted orientations. A memory macro also needs accurate boundary pins and internal behavior over process, voltage, and temperature corners.

Open conventional-process resources such as SKY130 provide documented transistor and standard-cell families. Their availability does not imply support for an experimental HZO/Al₂O₃/HZO device, its oxygen-reservoir electrode, or an oxide-channel integration sequence. A designer may use a conventional library for the controller while treating the new memory as a custom block, but the physical and electrical interface still requires characterization. SKY130 standard-cell documentation.

No compatible research-device PDK, foundry layer mapping, or characterized memory-macro views were acquired for this assignment. The feasible implementation therefore includes generic digital synthesis and an abstract research macro. It does not claim standard-cell placement/routing or transistor-level implementation of the experimental memory. Installing a conventional PDK alone would not resolve the research-device boundary.

Static timing analysis compares path delays with clock and interface constraints without enumerating every input waveform. Setup time constrains when data must settle before a sampling edge; hold time constrains how long it must remain stable after that edge. Clock skew can help one requirement and hurt the other. A functional testbench with zero-delay generic gates cannot establish either margin.

8.4 The delivered abstract views are deliberately explicit

LEF describes a macro footprint and 25 boundary pins. GDS contains a boundary and 128 symbolic bit locations on arbitrary layer numbers. The macro ledger states geometry, protocol timing, unknown power, and the distinction between abstract layers and foundry layers. The file formats are editable and machine-readable; their existence is not physical signoff.

The LEF geometry passes pin-containment checks, SVG documents pass XML parsing, and the GDS byte stream passes record-boundary and geometry-count checks. These are format and geometry checks. They are not foundry design-rule checking or layout-versus-schematic verification. No characterized Liberty timing/power file is invented for the research macro.

To replace the abstract block with a real macro, obtain a consistent set: device/process model, bitcell layout, decoder and driver implementation, sense strategy, operating voltages, DRC/LVS decks, parasitic extraction rules, timing/power characterization, and interface corner data. All must refer to the same stack and process revision. Combining attractive parameters from unrelated papers cannot supply that consistency.

8.5 Placement is an optimization problem with geometry

The numerical placement exercise uses a separate idealized 10 by 10 mm plane. Three interface points have weights representing relative traffic. For candidate macro center $(x,y)$ and interface points $(x_i,y_i)$, weighted Manhattan wirelength is $L_w=\sum_iw_i(|x-x_i|+|y-y_i|)$. The metric approximates orthogonal routing length; it does not represent extracted RC delay.

Without obstacles, minimizing weighted absolute distances separates into an x and a y weighted-median problem. An obstacle or keepout can invalidate a naive unconstrained median. The script enumerates a 0.25 mm grid, excludes a central keepout, and finds a minimum cost of 26 weighted mm. Several positions can tie; the chosen first minimizer is not a unique physical optimum. The check is global over the enumerated grid only.

Replacing points by finite rectangles adds boundary containment and non-overlap constraints. Adding congestion requires accounting for competing nets and routing capacity. A shortest geometric route may be worse electrically if it passes through a hot region or uses resistive layers. This sequence makes the modeling ceiling visible rather than declaring a placement “optimized” without its objective.

8.6 Process temperature, operating temperature, and packaging

A process thermal budget describes temperatures, durations, and sequence during fabrication. Operating temperature describes conditions while the device performs its function. A brief anneal can improve crystallinity while long electrical operation at a lower temperature causes degradation. For monolithic three-dimensional integration, later processing must also preserve structures already built below.

The oxide-channel thermal study illustrates this dependence on sequence and capping. A reported 650 °C survival interval applies to its tested devices and protocol. It does not imply that every metal, dielectric, bond interface, or package can survive the same sequence. Nor does “BEOL-compatible” establish an integrated full-chip yield without a complete process demonstration. Thermal-processing study.

During operation, a simple thermal-resistance model gives $T_j=T_a+R_\theta P$, where $T_j$ is junction temperature, $T_a$ ambient or reference temperature, $R_\theta$ thermal resistance in K/W, and $P$ dissipated power. This lumped steady-state relation omits spatial hotspots and transients. Since leakage and reliability depend on temperature, a memory-efficiency claim can be altered by package placement and cooling.

8.7 Density is not usable silicon per dollar

Under a simple independent-defect model, if fatal defects occur with mean density $D_0$ per area and a die has sensitive area $A$, the zero-defect probability is $Y=e^{-D_0A}$. This follows from the zero-count probability of a Poisson process with mean $D_0A$. Doubling density at the device level may reduce area, but introducing a less mature process can increase effective defect density or add failure modes absent from this model.

Redundant rows, repair, chiplets, and known-good-die testing can change the effective yield calculation. Three-dimensional bonding adds its own interface and alignment yield. A layered-memory density projection should therefore state whether it counts cell area, macro area, wafer yield, or usable packaged capacity. These are different denominators.

8.8 A memory macro is a set of mutually consistent views

Our running integration task is to place a new memory next to a conventional digital controller without inventing missing manufacturing evidence. A macro is a block whose internal implementation is usually hidden from the chip-level placer. Its boundary must nevertheless describe enough behavior and geometry for the surrounding chip to be designed correctly. A footprint alone answers where the block fits. It does not answer when data arrive, how much current a write draws, or which supply voltages are permitted.

Separate four views. A logical view gives ports, operation semantics, and functional behavior. A physical abstract gives size, legal orientations, pins, and routing obstructions. A timing and power view gives constraints and response over characterized conditions. A detailed implementation gives actual devices and geometry, with verification evidence. The views must identify the same revision and the same operating modes. If a pin moves in one view while another remains stale, a design can appear correct in each tool separately and fail when assembled.

The delivered LEF and GDS files intentionally supply only an abstract geometric exercise. Their pin-containment and record-format checks are useful because malformed or contradictory geometry is still a real error. They do not provide a foundry layer map or transistor connectivity. The macro ledger preserves that distinction. A research device becomes a characterized macro through measured or validated behavior and process-specific implementation, not through a change in filename.

The documented conventional SKY130 libraries illustrate what a library ecosystem supplies for supported devices. They do not authorize a new hafnia stack, oxide channel, or oxygen-exchange electrode within that process. One could build a conventional controller in a supported technology and connect it to a separately fabricated research memory, but voltage levels, packaging, test access, and timing still need a joint contract.

8.9 Replace point placement with legal rectangles

The original placement project uses a point to expose the weighted-distance objective. To place an actual rectangular macro with width $w$ and height $h$ in a chip of width $W_c$ and height $H_c$, its center must satisfy $w/2\le x\le W_c-w/2$ and $h/2\le y\le H_c-h/2$. These inequalities keep the entire rectangle within the chip. A point that lies outside a keepout can still place part of the macro inside it.

For an axis-aligned rectangular obstacle $[x_1,x_2]\times[y_1,y_2]$, non-overlap requires at least one separation condition: the macro lies wholly left, right, below, or above the obstacle. Equivalently, its center must stay outside the obstacle expanded by half the macro dimensions in each direction. This expanded obstacle is a configuration-space construction: geometry of a moving rectangle becomes geometry of a forbidden center region. Required routing or thermal clearance expands it further.

Weighted Manhattan distance separates into independent x and y sums when there are no coupled constraints. In one dimension, the derivative of $\sum_iw_i|x-x_i|$ away from data points is weight to the left minus weight to the right. A minimum occurs where neither side contains more than half the total weight: a weighted median. This derives the placement rule and explains why equal split weights can produce an interval of equally optimal locations.

Obstacles break the naive median solution because the unconstrained minimizer may be illegal. Enumeration over a grid provides a global optimum over that finite grid if every legal point is considered. It does not certify the continuous optimum or routability. The existing 0.25 mm grid result of 26 weighted mm is therefore an objective-specific benchmark. A physical optimizer would also account for finite pin positions, routing layers, congestion, supply delivery, and clock relationships.

A useful extension first replaces the point with a 1 by 1 mm rectangle and expands the keepout by 0.5 mm. Compare the feasible set before reoptimizing. If a previous optimum disappears, that is not optimizer instability; the earlier model admitted geometrically impossible candidates. Then change traffic weights and observe whether the optimum moves toward the interface carrying the greatest useful traffic. This connects workload assumptions to placement decisions without pretending Manhattan length is an extracted delay.

8.10 Derive a coupled thermal network

A single thermal resistance cannot distinguish a hot logic tier from a neighboring memory tier. Consider two steady-state nodes with temperature rises $\theta_1=T_1-T_a$ and $\theta_2=T_2-T_a$ above ambient. Let $g_1$ and $g_2$ be conductances from each node to ambient, and $g_c$ their mutual conductance, all in W/K. If dissipated powers are $P_1$ and $P_2$, heat balance gives

$$\begin{bmatrix}g_1+g_c&-g_c\\-g_c&g_2+g_c\end{bmatrix}\begin{bmatrix}\theta_1\\\theta_2\end{bmatrix}=\begin{bmatrix}P_1\\P_2\end{bmatrix}.$$

The off-diagonal terms have negative signs because heat flowing from one node into the other reduces the first node's loss when the neighbor warms. Add the two equations and the mutual terms cancel: total power leaves through the two ambient paths. This cancellation is an energy-conservation check. With positive ambient conductances the matrix is positive definite, giving a unique steady-state solution for fixed powers.

Take synthetic conductances $g_1=2$, $g_2=1$, $g_c=1$ W/K and powers 20 and 5 W. The depth laboratory solves the system and obtains rises of 9 K and 7 K. Without coupling, the rises would be 10 K and 5 K. Coupling cools the hotter node and heats the cooler one. A memory consuming little power can therefore experience substantial temperature from adjacent logic. Its retention and noise margin depend on placement, not just its own switching energy.

Transient temperature adds thermal capacitances $C_{\theta,i}$ in J/K: $C_\theta\dot\theta+G\theta=P(t)$. The eigenvalues of $C_\theta^{-1}G$ set relaxation rates in this linear model. Short pulses can create electrical stress without reaching the steady-state temperature, while repeated bursts can accumulate heat. A cycle-averaged power estimate is adequate only when the relevant thermal dynamics smooth the workload on the time scale of interest.

Temperature-dependent leakage introduces feedback. For a scalar model $T=T_a+R_\theta P(T)$, a small perturbation is amplified by local slope $R_\theta P'(T)$. A steady solution loses small-signal thermal stability in the simple dynamic model when that slope exceeds one. Merely finding a numerical solution to the steady equation does not prove stable operation. A ferroelectric-memory proposal needs compatible electrical and thermal conditions over the intended workload, especially when retention is exponentially temperature sensitive.

8.11 Thermal budget is an accumulated process history

The oxide-channel thermal-processing study compares specified capped IGO and IWO structures under stated anneal durations. The useful inference is conditional survival of those test structures after exposure. To use that evidence in a monolithic three-dimensional flow, enumerate every later process step and its effect on already fabricated layers. The final anneal is not the only exposure: deposition, cleaning, bonding, and rework can all contribute.

A simple activated-damage model defines dose $D=\int k[T(t)]\,dt$, where rate $k(T)=k_0\exp[-E_d/(k_BT)]$ and $E_d$ is an activation energy. Two process histories are equivalent under this model when their integrals match. This explains why maximum temperature alone is insufficient. A short high-temperature step can dominate a long mild step, depending on the activation energy. Different degradation mechanisms have different activation energies and chemical dependencies, so one scalar thermal dose is rarely universal.

Ambient chemistry matters independently of temperature. An oxygen-containing exposure can change oxide-channel carriers or electrode chemistry, while a reducing exposure can change vacancy populations. Mechanical stress and capping alter diffusion paths and phase stability. The earlier materials chapters therefore supply inputs to process integration: phase fractions, defect motion, and interface reactions must remain acceptable through the complete sequence. A label such as back-end compatible is a hypothesis about that sequence until supported by an integrated demonstration.

Package assembly introduces a separate sequence after device fabrication. Bonding and encapsulation can impose heat and stress, while contacts and interconnects impose their own voltage and current constraints. An experimental transistor that survives a laboratory anneal has not thereby qualified its package, power delivery, or thermal cycling. The distinction is operational: list which structure was tested, when it was tested, and which properties were remeasured afterward.

8.12 Yield models change the meaning of density

The Poisson yield expression assumes independent spatial defects with one effective fatal-defect density. If defect density varies from region to region, a mixture can change the zero-defect probability. One common teaching model gives $Y=(1+D_0A/\alpha_y)^{-\alpha_y}$, with positive clustering parameter $\alpha_y$. As $\alpha_y$ tends to infinity it approaches $e^{-D_0A}$. This follows from the limit $(1+x/n)^n\to e^x$. It is a statistical model, not evidence that a particular process has that defect distribution.

At defect load $D_0A=1$, Poisson yield is 0.367879. The clustered model with $\alpha_y=2$ gives 0.444444. Clustering can leave more nearly defect-free regions while concentrating defects elsewhere, raising zero-defect probability at the same mean in this model. That does not imply clustering is desirable for every repair scheme or die geometry. It demonstrates that mean defect density alone does not fully specify yield.

For two independent tiers bonded without prior die selection, if both tier yields are $Y$ and bond yield is $Y_b$, usable pair yield is $Y^2Y_b$. With $Y=e^{-1}$, the tier contribution is only 0.135335. Selecting known-good dies before bonding can avoid pairing obviously bad tiers, so the conditional bond-stage yield may approach $Y_b$ for the screened population. The cost of producing and testing those known-good dies remains. Reporting only conditional assembly yield can hide the upstream wafer losses.

A simplified cost per useful bit is total manufacturing and test cost divided by expected good delivered bits. If raw bits per die are $N_r$, usable fraction is $f_u$, and package yield is $Y_p$, the denominator is proportional to $N_rf_uY_p$. Doubling raw density while halving yield leaves this denominator unchanged before any new process cost. ECC, spare rows, alignment keepouts, and peripheral circuits all affect useful density. A domain-size record and a package-cost improvement are therefore far apart in the evidence chain.

8.13 Programming pulses create a power-delivery problem

A memory that draws low average power can still require a large transient current when many bits program together. A local supply path has resistance $R_p$ and inductance $L_p$. A simple voltage-droop estimate is $\Delta V\simeq I R_p+L_p\,dI/dt$, before accounting for decoupling and distributed resonance. The resistive term depends on current magnitude; the inductive term depends on how abruptly current changes. A faster pulse can worsen the latter even if its total charge is unchanged.

A local decoupling capacitance $C_d$ supplies a current deficit over a short interval, with voltage change approximately $\Delta V=\Delta Q/C_d$. For a synthetic 10 mA deficit lasting 1 ns, keeping droop below 10 mV needs at least 1 nF in the ideal charge-only estimate. Real placement, equivalent series resistance, and inductance determine whether that capacitance is effective at the required time scale. The example shows why peak programming concurrency and package design must be considered together.

Reducing simultaneous writes can ease droop but lower throughput. Staggering banks changes the activity schedule, which changes queueing and effective service time. A device-level energy gain can therefore be consumed by a throughput restriction if its new pulse shape imposes worse peak-current demands. The appropriate comparison holds delivered throughput and error targets constant while measuring both average energy and transient supply margins.

1. A cool memory next to hot logic

In the two-node thermal example, set memory power to zero while logic remains at 20 W. Find both temperature rises.

Solution. Solve $3\theta_1-\theta_2=20$ and $-\theta_1+2\theta_2=0$. The second gives $\theta_1=2\theta_2$, so $5\theta_2=20$, hence memory rises 4 K and logic 8 K. Zero self-power does not imply ambient temperature. Any retention estimate for the memory must use its actual thermal environment.

2. Distinguish screening from overall yield

Each of two tiers has 80% manufacturing yield, and bonding succeeds 98% of the time. Compare unscreened pair yield with conditional bonding yield after perfect screening.

Solution. Unscreened yield is $0.8^2(0.98)=0.6272$. After perfect screening, 98% of assembled known-good pairs survive bonding, but obtaining each good tier consumes on average $1/0.8=1.25$ manufactured tiers under the simple model. Screening improves use of the assembly process; it does not erase wafer cost or failures missed by imperfect tests.

3. Name the evidence needed for a 500 MHz claim

The controller simulates correctly with a 2 ns testbench clock. What additional evidence would justify a physical 500 MHz interface?

Solution. Use characterized cell and macro timing at supported voltage and temperature corners, a mapped and physically implemented netlist, extracted interconnect, clock uncertainty and skew, and setup/hold analysis for all relevant paths. Verify analog memory completion and interface sampling separately. A zero-delay simulator accepts the chosen clock period because it does not model those delays; the testbench frequency is stimulus, not measured capability.

8.14 Carry operating conditions through the interface

A macro timing number is meaningful only with its load, input slew, voltage, temperature, and internal state. Input slew is the time scale of an incoming signal transition; output load is the capacitance the macro must drive. A slowly rising select signal and a heavily loaded output can change delay even if the cell physics is unchanged. Characterization therefore evaluates a family of conditions rather than assigning one universal access time.

Process, voltage, and temperature corners are selected conditions intended to cover relevant variation. A slow digital transistor corner is not automatically the worst ferroelectric retention corner or the worst read-window corner. Programming, reading, retention, and peripheral logic can have different worst cases. The combined specification must state which combinations are physically meaningful and which guarantee is required. Combining every independently worst parameter can be conservative; combining only mutually favorable ones is not a guarantee.

For a synchronous path, define clock skew $t_{\rm skew}$ as capture-clock arrival minus launch-clock arrival. Positive skew gives data more time for the next capture edge, helping setup. The setup inequality becomes $t_{cq,\max}+t_{pd,\max}+t_{\rm setup}\le T_c+t_{\rm skew}$ before uncertainty margins, where $t_{pd,\max}$ is maximum data-path delay. For hold, the new data must not reach the capture register too early after its current edge: $t_{cq,\min}+t_{pd,\min}\ge t_{\rm hold}+t_{\rm skew}$. The same positive skew makes hold harder.

This opposing effect explains why simply delaying the capture clock cannot solve timing universally. Setup repair can create a hold violation, and a buffer inserted to repair hold can consume setup margin. Clock uncertainty, variation, and asynchronous interfaces add further conditions. A generic synthesized controller has none of the characterized path delays needed to evaluate these inequalities, even when its functional sequence is completely understood.

At a memory boundary, an output may be valid only after sense completion and remain valid for a limited interval. The receiver needs a compatible sampling rule. If the macro is asynchronous, a handshake can signal stable data; if synchronous, its timing model must relate output validity to a clock edge. The ideal behavioral memory in this course exposes data combinationally from an array index. That is a simulation convenience, not a specification for a fabricated macro's read aperture.

Temperature couples timing and retention budgets

Suppose an array is placed closer to compute to shorten wires. The thermal network can raise its temperature, shifting read-current distributions or reducing retention. The shorter wires improve one timing term while the hotter device can worsen another reliability term. An integration optimizer should therefore use a vector of outcomes: path delay, energy, temperature, and error margin. Reducing all of them to wirelength alone loses the mechanism that can reverse the placement choice.

For an illustrative activated retention time $\tau=\tau_0e^{U/(k_BT)}$, logarithmic temperature sensitivity is $d\ln\tau/dT=-U/(k_BT^2)$. At 300 K and assumed $U=0.7$ eV, the magnitude is about 0.0903 K⁻¹. A small 1 K increase corresponds locally to roughly a 9% reduction in lifetime on the logarithmic scale. The finite change must use the exponential ratio rather than extend the linear approximation indefinitely. These are consequences of the assumed barrier model, not measured temperature sensitivity of a source device.

The example shows why a few kelvin from neighboring logic can matter even when memory power is small. It also shows why reporting a process-survival temperature as an operating-temperature specification is so misleading: the relevant question is not only whether the structure remains intact, but how its service metrics change over time under bias. Temperature-dependent measurements at the intended operating conditions are part of macro qualification.

4. Repair one timing constraint without hiding another

A path has maximum data arrival 1.8 ns including clock-to-output, setup requirement 0.2 ns, clock period 2 ns, and zero skew. Its minimum data arrival is 0.1 ns and hold requirement 0.05 ns. What happens if capture skew becomes +0.1 ns?

Solution. Setup slack changes from $2-(1.8+0.2)=0$ to 0.1 ns. Hold requires minimum arrival at least $0.05+0.1=0.15$ ns, so the 0.1 ns path now violates hold by 0.05 ns. A timing improvement for the maximum-delay constraint created a failure in the minimum-delay constraint. Physical verification must check both across the relevant corners and clock uncertainties.

8.15 Foundation exercises and solutions

5. Read a physical-design claim

Does a clean GDS file plus a passing controller testbench establish a fabricated memory?

Solution. No. GDS stores geometry; the testbench establishes selected digital behavior. Process layers, devices, DRC, LVS, extraction, characterization, and fabrication evidence remain necessary. An abstract macro cannot become a physical FeFET simply by naming its cell “ferroelectric.”

6. Thermal headroom

If $T_a=35$ °C and $R_\theta=0.4$ K/W, what steady-state power reaches a 75 °C junction limit?

Solution. $P=(75-35)/0.4=100$ W under the lumped model. A hotspot can reach the limit earlier; validate the thermal resistance and spatial model before treating 100 W as a product specification.

7. Yield tradeoff

A Poisson model has $D_0A=0.2$. What happens if area doubles at unchanged defect density?

Solution. Yield changes from $e^{-0.2}\simeq0.819$ to $e^{-0.4}\simeq0.670$. This model excludes clustering and repair. It demonstrates why area reductions and process maturity must be evaluated together.
